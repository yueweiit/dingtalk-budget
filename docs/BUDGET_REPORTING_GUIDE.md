# 预算报表与审批效率口径

本文供财务、业务和 OA 维护人员共同使用。报表暂不提供项目维度；在表单具备稳定项目 ID 前，不按项目名称推测归属。

## 数据范围与权限

- 预算、支出和审批数据按页面选择的开始、结束日期查询，结束日期包含当天。
- 数据库和接口统一使用 UTC（协调世界时）进行计算；审批节点 Excel 统一转换为北京时间（Asia/Shanghai，UTC+8）并显示到秒。
- 超级管理员可以查看全部预算报表、审批效率和审批节点导出。
- 部门主管只查看权限范围内的预算和支出，不返回跨部门审批人明细。
- 审批效率只统计 OA 中已启用、未删除的流程模板和未删除审批实例。

## 预算执行口径

- 预算金额来自预算申请表。生产预算和非生产预算分别解析后，按稳定部门 ID 和预算月份汇总。
- 实际支出只统计整单已完成且最终同意，并具有审批完成时间的记录；月份按审批完成时间的 UTC 月份计算。
- 已确认付款事件按付款时间和付款金额入账；同一业务存在合格付款事件时，不再重复统计整单完成金额。
- 工资、社保公积金、办公场地、个税等拆分表单按明细中的部门分别入账，不使用表单服务主体代替拆分部门。
- 列表、图表和导出使用相同的部门 ID、金额和时间口径。部门名称仅用于展示，不作为权限或关联键。
- 预算为 0 或无预算的部门不触发 90% 和超预算通知，但实际支出仍按既定报表规则保留。

## 审批效率口径

- 流程总耗时：审批实例 `create_time` 到 `finish_time`。进行中实例不进入平均完成时长。
- 平均完成时长：已完成且起止时间有效的流程总耗时平均值。
- 节点耗时：审批任务 `start_time` 到 `end_time`；进行中节点计算到查询时刻。
- 正式节点超时标准：24 小时。
- 节点超时率：耗时超过 24 小时的节点数 / 具有有效起始时间的节点数。
- 缺少起始时间、结束时间早于起始时间的数据不参与时长和超时率计算，但实例总数仍保留，以便发现数据完整性问题。

## 页面与导出

- 可视化报表展示审批实例数、平均完成时长、当前审批中数量、平均节点耗时、节点超时率和分流程汇总。
- 超级管理员导出的预算报表新增“审批效率汇总”和“审批节点明细”两个工作表。
- 节点明细包含流程、实例、节点、审批人 UserID、审批人姓名、起止时间、耗时和超时标记。
- OA 数据库暂时不可用时，预算报表继续返回，并给出审批效率不可用警告。
- 生产环境使用 `OA_DB_*` 配置只读访问 OA 库；数据库账号只需审批实例、任务和流程模板的查询权限。

## 验收用例

1. 选择一个自然月，页面实例数应与 OA 中启用流程、未删除且当月发起的实例数一致。
2. 一个节点等待 25 小时应标记超时；等待恰好 24 小时不标记超时。
3. 已完成流程进入平均完成时长，进行中流程不进入该平均值。
4. 缺少节点开始时间的记录不进入节点超时率分母。
5. 超级管理员导出应包含两个审批工作表；部门主管导出不应包含审批人明细。
6. OA 只读库不可用时，预算报表仍应生成，并显示审批效率不可用警告。

## 维护注意事项

- 修改超时标准时，必须同时核对 OA 超时通知和本报表口径，不能形成两套阈值。
- 新增或停用监听流程应维护 OA 的流程模板启用状态；报表不另建流程名单。
- 修改部门、拆分、付款或时间口径时，应同时回归列表、可视化报表、Excel 和预警通知。
- 在获得稳定项目 ID 前，继续保持项目维度关闭。
